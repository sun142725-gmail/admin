## flow 迁移交互设计（方案讨论）
- 选定方向：北向复用 Node /api/svc 网关转发（@All + 流式回传，SSE 可透传，零改造）；南向 Go 反向调 Node 新增 /internal/ai 阻塞式接口
- 关键事实：引擎只聚合流式文本不消费片段 → Go↔Node 无需流式，阻塞 POST + 180s 超时即可；用量记录保持 Node 单一写入路径
- DB 写所有权：Go 拥有 flow_run/flow_run_node；flow_definition CRUD 暂留 Node 避免双写；SSE 事件由 Go 直产、经网关透传
- 暂不引入 MQ（单实例内存态够用），多实例时再上 Redis
