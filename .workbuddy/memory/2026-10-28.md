## 二期后补：lazyPage 命名导出崩溃修复（用户实测发现）
- 症状：/graphic 与 /prompts 两页渲染崩溃 "Lazy element type must resolve to a class or function"
- 根因：router 的 lazyPage 助手按 module['Name'] 取组件（命名导出惯例），新建两页写成 export default → module[name]=undefined
- 修复：两页改回 export const XxxPage: React.FC = () => {}（存量惯例）
- 防线升级：scripts/check-imports.mjs 扩展——校验所有相对导入可解析 + lazyPage 注册页必须有命名导出；npm run build = tsc + check + vite build，npm run check 单独可用；均用"故意注入错误验证防线会红"的方式自证
- 教训：新页面必须复制存量页面的导出方式；前端验证必须跑 vite build（tsc 不查 CSS 路径/运行时导出）
