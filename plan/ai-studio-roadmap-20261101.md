# AI 制片厂 · 自媒体方向扩展路线图（2026-11-01）

> 调研对象：白日梦 AI / 极虎漫剪 / 绘唐 3（小说推文赛道）、剪映图文成片（精修环节）、
> 即梦（一站式 AI 片场）、可灵（可控性/首帧锁定）、CreBee / 蚁小二 / 融媒宝 / 矩阵通（发布矩阵与数据）。
> 结论：小说推文赛道已高度自动化，工具集中在四大模块——生产闭环补全、发布矩阵、数据回流、批量化降本。

## 现有能力盘点（已完成）
- 小说 → 章节 → 分镜 → 首帧 → 视频片段 → 合并成片（novel pipeline，断点续跑）
- 分镜片段级控制（锁定原文 / 视觉任务 / 镜头推进 / H3 模式 / 首帧锁定）
- TTS 配音（落盘）+ SRT 字幕（生成，未烧录）
- 流程编排 DAG（llm/image/video/http/tts 节点，多候选故障转移）
- 提示词库（模板 / 同步去重 / 一键生成 / 以图换图）
- AI 画布（生图谱系：以图续画）
- usage log（模型调用记录，成本核算的数据底座）
- 通知体系（模板 / 通道 / 发布记录——可平移到发布矩阵）

## 第一梯队 · 生产闭环补全（自媒体变现刚需，建议先行）

| 功能 | 说明 | 与现有架构的关系 | 预估量级 |
|---|---|---|---|
| 角色一致性 | 角色卡（形象参考图 + 外观描述），分镜生成时注入参考图，保证多镜头同一角色形象 | referenceImages 通道已通（AI 画布续画已验证），分镜生成注入即可 | 中 |
| 封面生成 | 模板化封面（标题花字 + 首帧/生成底图），点击率命脉 | 提示词库模板 + 生图端点复用；ffmpeg 叠字 | 小 |
| 多规格输出 | 9:16 竖屏（抖音/快手/视频号）/ 16:9 / 1:1，分镜按规格重构 | 生成端 size 已参数化；合成端 ffmpeg 裁切/重构 | 中 |
| 字幕样式化 | SRT → 硬字幕烧录：描边/花字/关键词高亮/位置/字号 | ffmpeg subtitles 滤镜 + 样式配置 | 中 |
| BGM 与混音 | BGM 素材库 + 自动配乐、TTS/BGM 音量 ducking、成片响度统一 | ffmpeg amix/sidechain；TTS 音轨已有 | 中 |

## 第二梯队 · 发布与运营闭环

| 功能 | 说明 | 参考模式 |
|---|---|---|
| 发布矩阵 | 平台账号管理（抖音/快手/B站/视频号/小红书）+ 一键多发 + 定时发布 + 发布记录与状态 | CreBee / 蚁小二 / 融媒宝；站内信「模板/通道/发布记录」架构可平移；技术上：平台开放 API 优先，无 API 走浏览器自动化 |
| 数据回流 | 各平台播放/点赞/评论/涨粉汇总，按作品/账号/周期视图，爆款识别 | 矩阵通 100+ 数据维度思路；先做人工录入/CSV 导入，再做 API |
| 成本核算 | 每集/每本书的 token / 生图 / 生视频 成本与金额报表 | usage-log 已有 kind/modelId/latency，补单价配置与聚合报表 |
| 合规 | 敏感词检测、AIGC 内容标识（平台强制）、原创度提示 | 发布前检查链，接入发布矩阵流程 |

## 第三梯队 · 效率与规模化

| 功能 | 说明 |
|---|---|
| 批量生产 | 多书并行任务队列、模板化生产流（一套配置吃多本书）、失败自动重试与夜间调度 |
| 爆款方法库 | 选题库 / 标题库 / 钩子模板（黄金三秒）；对标视频拆解（镜头分割 → 反推提示词，小鸟 AI「AI 反推」模式） |
| 数字人口播 | 口播视频（数字人 + 语音克隆），自媒体知识/口播赛道扩展 |
| 协作与审片 | 多人协作、审片批注、版本管理 |

## 推荐节奏（结合现状的最短路径）
1. **角色一致性 + 封面生成**（提示词库/以图换图通道直接复用，性价比最高）
2. **BGM 混音 + 字幕烧录 + 竖屏输出**（成片真正可发布的前置条件）
3. **发布矩阵 MVP**（账号管理 + 手动一键多发 + 发布记录，站内信架构平移）
4. **数据回流 + 成本核算**（先 CSV，后 API）
5. **批量生产与爆款方法库**（规模化阶段）
