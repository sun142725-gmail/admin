## 重构大事纪模块使用公共全局组件

用户要求所有 dialog、日期选择器等组件必须使用公共全局组件，没有就在 shared 里面封装。

### 新增共享组件
- `src/shared/components/BaseDatePicker.vue` — 封装 Vant DatePicker + Popup，支持 precision='day'|'month' 切换年月日/仅年月，自动全局注册为 `<base-date-picker />`

### 重构变更
- `MilestoneEditDialog.vue` — `van-popup` → `SelfDrawer`（底部抽屉，内置滚动 + footer 插槽）；`van-date-picker` + `van-popup` → `BaseDatePicker`；`van-button` → `BaseButton`
- `MilestonesView.vue` — `EmptyState` 本地组件 → `BaseEmpty` 全局组件
- `MilestoneSummaryView.vue` — `EmptyState` → `BaseEmpty`；`van-button` → `BaseButton`

### 共享组件库清单（src/shared/components/，通过 index.js 自动全局注册）
- BaseButton / BaseEmpty / BaseLoading / BaseModal / BaseTag / BaseImage / BaseCard / BaseScroll / BaseSwiper / BaseTabs
- BaseDatePicker（新增）
- SelfForm / SelfFormItem / SelfDrawer / SelfUpload
