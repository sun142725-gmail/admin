## 更新：密码登录改为统一 account 字段

### 背景
后端 `/api/auth/login` 接口更新，支持 `account + password` 登录，account 可为手机号、邮箱或用户名；同时兼容原 `username + password`。

### 改动

**1. services/auth.js**
- `passwordLogin` 接口路径从 `/auth/password/login` 改为 `/auth/login`
- payload 从 `{ channel, target, password }` 改为 `{ account, password }`

**2. utils/validators.js**
- 新增 `isUsername` — 用户名校验（3-20 位，字母开头，字母/数字/下划线）
- 新增 `isAccount` — 统一账号校验（手机号 | 邮箱 | 用户名）

**3. LoginView.vue**
- 密码登录模式：移除 channel tab，使用单一 account 输入框，placeholder 为「手机号 / 邮箱 / 用户名」，图标用 manager-o
- 验证码登录模式：保留 channel tab（手机号/邮箱），因为发验证码需要区分渠道
- 表单字段从 `form.target` 统一改为 `form.account`，密码模式校验用 `isAccount`，验证码模式仍用 `validateTarget`

**4. stores/auth.js**
- `loginByPassword` 无需改动，只是透传 payload（现在传 `{ account, password }`）

## 更新：修复验证码输入框 icon/按钮错位 + 失焦黑框闪烁

### 问题
1. 验证码输入框的盾牌 icon 和「发送验证码」按钮与输入框垂直方向不对齐（截图反馈）。
2. input 失去焦点时会出现短暂黑框（移动端浏览器默认 outline）。

### 修复（styles/index.css）
- `.auth-input-icon` / `.auth-input-action` 从 `top-0 + h-[48px]` 改为 `top-1/2 -translate-y-1/2`，确保真正垂直居中。
- `.auth-input` 增加 `-webkit-appearance: none; appearance: none;` 并显式声明 `outline: none`。
- `.auth-input:focus` 显式 `outline: none`，避免移动端 blur 时 outline 闪烁。
- `.auth-code-btn` 改为 inline-flex 并垂直居中，避免文字/按钮在不同浏览器中对齐偏差。
