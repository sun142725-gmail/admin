# 2026-08-07 工作日志

## Auth 模块 404 排查

### 排查结果
逐个 curl 测试后端所有 auth 接口，对照后端 `AuthController` 源码：
- `POST /auth/login` ✅ — `@Post('login')`，接受 `{ account, password }`
- `POST /auth/code/send` ✅ — `@Post('code/send')`
- `POST /auth/code/login` ✅ — `@Post('code/login')`
- `POST /auth/code/reset-password` ✅ — `@Post('code/reset-password')`
- `POST /auth/refresh` ✅ — `@Post('refresh')`
- `POST /auth/logout` ✅ — `@Post('logout')`
- `GET /auth/profile` ✅ — `@Get('profile')`
- **`POST /auth/register` ❌ 404** — 后端 `AuthController` 无此方法

### 根因
后端从未实现 `/auth/register` 接口。不是路径改错，是后端缺少这个 endpoint。

### 额外发现
后端 `signTokens` 返回的 `profile` 只是 JWT payload（`sub/username/roles/permissions`），不含 `email/nickname/avatarUrl`。
完整 profile 需调 `GET /auth/profile`。

### 修复
- `stores/auth.js`: `loginByPassword` 和 `loginByCode` 登录成功后自动调 `loadAuthProfile()` 拉取完整 profile
- `loadAuthProfile` 失败时 fallback 到 JWT payload，不阻塞登录流程
