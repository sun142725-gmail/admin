# 功能测试用例文档 — HAS Web 模块

## 1. 测试概述
本文档针对 `has-web` 模块进行功能测试，覆盖登录注册、家庭管理、首页看板、家务待办、家庭公告、成员管理、大事纪、个人中心、设置等核心功能。旨在验证各功能模块的正确性、交互完整性和异常处理。

## 2. 测试环境
| 项目 | 说明 |
|------|------|
| 设备 | 移动端（iOS / Android 真机或模拟器均可） |
| 浏览器 | 微信内置浏览器 / Safari / Chrome |
| 网络 | 4G / Wi-Fi |
| 后端 | 对应测试环境 API 服务已部署 |

## 3. 前置条件
1. 测试账号已预置，或可通过注册流程创建。
2. 后端 API 服务正常运行。
3. 至少准备两个测试账号（一个作为房主，一个作为普通成员）。
