## 折叠态点击菜单 icon 直接展开侧边栏（去掉 hover 弹出）

- 问题：折叠态点击/划过父级（带子菜单）icon 只会弹出 popup 浮层；antd Menu 顶层 `onClick` 只对叶子项生效，且折叠态 submenu popup 是 hover 触发，`onOpenChange` 拦不掉
- 最终方案：折叠态不渲染子菜单——`buildMenuItems` 新增 `includeChildren` 参数，`items` useMemo 传 `!collapsed`，父级退化为普通项，hover 只剩 Tooltip；点击（含叶子与父级）统一由 `onClick` 拦截 → `setCollapsed(false)`
- 废弃方案：曾用 `onOpenChange` 拦截展开，但 hover 也会触发该回调导致鼠标划过就展开，已回退为简单版
- 顺手修复 MainLayout 存量 TS 错误：`buildMenuItems` 补返回类型 `MenuProps['items']`；`resources.ts` 导出 `MenuTreeNode` 并用 `http.get<never, T>()` 标注返回；`auth.ts` 的 `profile` 同样标注为 `NonNullable<AuthState['profile']>`
- 备注：全项目各页面存在大量同类 `AxiosResponse` 类型错误（拦截器运行时已解包 data，但未标注类型），属存量问题待后续统一修复
